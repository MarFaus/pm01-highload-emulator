Репозиторий: https://github.com/MarFaus/pm01-highload-emulator (отдельный, к pm01-weather-api не относится).
Задание препода от 15:32 — архив `Интерактивная_эмуляция_высоконагруженного_app.zip`: `emulator/highload.html` + `emulator/Лабораторная работа.docx` (6 работ). Кода нет, сдаётся отчёт.

## Запуск
- Эмулятор: открыть `emulator/highload.html` в браузере (нужен интернет для Tailwind/шрифтов с CDN).
- Playwright не открывает `file://` — поднимать сервер:
  `C:\Users\Public\kassa6379-tools\php\php.exe -S 127.0.0.1:8052 -t emulator`.
- Отчёт: `python ~/.claude/skills/lab-report/scripts/build_report.py docs/report/spec.json docs/report/Отчет_ЛР_Эмулятор_высоконагруженного_приложения.docx`.

## Решения
- Замеры сняты Playwright-скриптом через UI (ползунки `fill`, переключатели — `checked` + событие `change`, т.к. они `sr-only`), значения читались из глобальных `state`/`metrics` и совпадают с карточками.
- Модель детерминированная: те же настройки дают те же цифры.
- Работа 6: ни один из трёх вариантов не даёт встроенный зачёт «ЛР №5» (он требует 2 000 RPS и ≤ $1.20 одновременно); по заданию в бюджет укладывается только «5 App при 1 900 RPS».
